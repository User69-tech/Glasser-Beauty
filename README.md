# Glasser-Beauty
Glasser Beauty is a customizable Android launcher built to make the home screen feel expressive, polished, and personal. Its visual style combines luminous surfaces, soft gradients, rounded shapes, and frosted glass inspired by modern mobile interfaces.

The home screen supports app tiles, favourite shortcuts, Android widgets, and customizable placement. Users can add and remove apps, rearrange favourites, and resize supported widgets. A search field provides a quick way to find installed apps or start a web search. Long-pressing an app opens useful actions, including hiding it from the drawer, changing its icon, managing favourites, or opening its Android app information.

Glasser Beauty includes a searchable app drawer with two layout choices. The vertical layout presents apps in a familiar scrolling grid. Horizontal mode arranges apps into distinct, swipeable pages, with twenty app positions per page in a four-column by five-row layout. Hidden apps stay out of the regular drawer and can be managed from Beauty settings.

Personalisation options include light glass, Midnight, and Rose themes, compatible installed icon packs, individual custom app icons, and dock placement. A frosted drawer surface adapts to the selected theme and uses background blur where the Android version supports it. The drawer’s rounded frame, wallpaper-based blur, and dim scrim help visually separate browsing from the home screen. Gesture-driven transitions connect Home and the drawer, while standard Android app launching keeps installed apps accessible from the launcher.

Beauty settings provide controls for the app drawer, themes, icons, dock, and hidden apps, along with an About Creator section crediting Intisar Rahman. Glasser Beauty is a standalone launcher project with its own Android package, built separately from the original Glasser launcher. It is designed for Android phones and can be installed as a home app after building the project for everyday phone use.

        

## Build

Build the Android app with Gradle:

```powershell
.\gradlew.bat :app:assembleDebug
```

The ready-to-install debug APK is available at [releases/Glasser-Beauty.apk](releases/Glasser-Beauty.apk). The project source is in the repository root and app/.
